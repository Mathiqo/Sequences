What is a Term-to-Term Rule?

A sequence is an ordered list of numbers. Each number in the sequence is called a term.

A term-to-term rule tells you how to get from one term to the next.

Visual Model Example: Start at 2 and Add 3 each step.

5

The term-to-term rule is "Add 3".

Two-Step Rules & Working Backwards

Some rules combine two operations (e.g., "Multiply by 2, then add 1").

Function Machine Model:

3 → × 2 → + 1 → 7

To work backwards, undo the operations in reverse order: Subtract 1, then divide by 2.
